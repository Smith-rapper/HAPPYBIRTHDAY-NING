# OUR LITTLE UNIVERSE — Birthday Surprise Website ♡

เว็บเซอร์ไพรส์วันเกิดแบบหลายส่วน มีแอนิเมชัน กล่องของขวัญ จดหมายรัก คลังภาพ ความทรงจำ เค้กวันเกิด และปรับแต่งข้อความได้ในหน้าเว็บ

## วิธีเปิดใช้งาน

1. แตกไฟล์ `birthday_surprise_website.zip`
2. เข้าโฟลเดอร์ `birthday_surprise_website`
3. ดับเบิลคลิก `index.html` เพื่อเปิดใน Chrome, Edge หรือ Firefox
4. กดปุ่ม ⚙ ด้านบนเพื่อใส่ชื่อแฟน วันเกิด วันเริ่มคบกัน และแก้ข้อความรักเป็นเรื่องของคุณ
5. ในเมนู ⚙ สามารถเลือกรูปคู่สำหรับหน้าปก และเลือกไฟล์เพลงของคุณเองได้
6. กดปุ่ม “＋ เพิ่มรูปของเรา” ในส่วนคลังความทรงจำเพื่อใส่รูปได้หลายรูป
7. กดกล่องของขวัญเพื่อเปิดเนื้อหาที่ซ่อนอยู่ รหัสเริ่มต้นของกล่องลับคือ `love` (เปลี่ยนได้ใน ⚙)

## ของที่มีในเว็บ

- หน้าเปิดเซอร์ไพรส์พร้อมเอฟเฟกต์หัวใจและพลุ
- หน้าแรกพร้อมภาพหน้าปกและข้อความอวยพร
- ตัวนับถอยหลังถึงวันเกิดถัดไป และตัวนับจำนวนวันที่คบกัน
- เรื่องราวของเรา พร้อมข้อความเพิ่มเติม
- การ์ดเหตุผลที่รัก และเพิ่มเหตุผลของตัวเองได้
- คลังความทรงจำ: เพิ่มรูปหลายรูป เปิดดู และลบรูปที่เพิ่มเองได้
- กล่องของขวัญ 4 แบบ: จดหมายลับ คูปองเดต คำอธิษฐาน และกล่องรหัสลับ
- เค้กวันเกิดโต้ตอบได้ กดเป่าเทียนและจุดใหม่ได้
- จดหมายรักแก้ไขได้ ดาวน์โหลดเป็นไฟล์ TXT ได้
- คำสัญญา ปิดท้ายพร้อมหัวใจและพลุ
- เสียงบรรยากาศที่สร้างขึ้นในเว็บ หรือเลือกไฟล์เพลงส่วนตัว
- รองรับหน้าจอมือถือและคอมพิวเตอร์

## หมายเหตุเรื่องข้อมูล

- ข้อความตั้งค่าเก็บใน `localStorage` ของเบราว์เซอร์
- รูปหน้าปกและรูปความทรงจำเก็บใน IndexedDB ของเบราว์เซอร์เครื่องนั้น ไม่ได้อัปโหลดไปเซิร์ฟเวอร์
- เพลงที่เลือกเล่นจากเครื่องและจะไม่ถูกฝังลงใน ZIP โดยอัตโนมัติ
- ถ้าเปิดเว็บบนอุปกรณ์อื่น ข้อความ/รูป/เพลงในเครื่องเดิมจะไม่ย้ายตามไปด้วย
- Google Fonts เป็นตัวเลือกสำหรับฟอนต์สวยขึ้น หากไม่มีอินเทอร์เน็ต เว็บยังแสดงได้โดยใช้ฟอนต์สำรองของเครื่อง

## แก้โค้ดเพิ่มเติม

- `index.html` — โครงสร้างหน้าเว็บและเนื้อหาหลัก
- `styles.css` — ธีม สี แอนิเมชัน และ responsive layout
- `app.js` — การทำงานของปุ่ม ระบบตั้งค่า คลังรูป เสียง พลุ และกล่องของขวัญ
- `assets/` — ไอคอนและภาพตัวอย่าง SVG ที่ใช้แทนรูปจริง
